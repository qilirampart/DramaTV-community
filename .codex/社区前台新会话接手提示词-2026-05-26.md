# 社区前台新会话接手提示词

适用时间：`2026-05-26`

这份文档用于让新的聊天线程快速接手 `DramaTV 社区前台后续优化`，避免再从超长历史对话里手工捞状态。

## 1. 当前项目一句话概况

`DramaTV` 目前是一个单仓多应用项目：

- 社区前台：`E:\点众\DramaTV社区搭建\apps\web`
- 社区后台：`E:\点众\DramaTV社区搭建\apps\admin`
- 社区后端：`E:\点众\DramaTV社区搭建\apps\server`

当前社区前台主链路已经基本打通，项目阶段已经从“基础功能搭建”切到“稳定性、性能、交互和云端一致性优化”。

## 2. 技术栈速览

- 前台：`Next.js 16.2.2` + `React 19.2.0` + `TypeScript`
- 帖子编辑器：`TipTap 3`
- 后端：`Spring Boot 3.5.13` + `Java 17`
- 数据层：`PostgreSQL` + `Redis` + `Flyway`
- 媒体存储：`阿里云 OSS`
- 当前媒体展示链路：
  - 上传：`Browser -> apps/server -> OSS`
  - 展示：`Browser -> /media/** -> apps/server -> 私有 OSS`

## 3. 当前内容模型

社区前台当前主内容分为四类：

1. `视频提示词`
2. `图片提示词`
3. `工作流`
4. `帖子`

补充说明：

- 工作流当前仍是占位内容，详情页和发布页已存在，但尚未真正对接画布运行时。
- 提示词类现在已经支持更细的分类体系，后端 taxonomy 已经不是前端硬猜。
- 帖子是独立页面体系，不归入“提示词/工作流资源流”。

## 6. 当前阶段最重要的规则

新会话不要偏离下面这些已经确认过的规则：

- 中文文档读取和写入必须显式按 `UTF-8`
- 手工改文件统一优先用 `apply_patch`
- 做社区前台任务时，进度写到：
  - `E:\点众\DramaTV社区搭建\.codex\progress-community.md`
- 如果改动会影响前后台共享接口、共享状态或共享数据库语义，还要同步写：
  - `E:\点众\DramaTV社区搭建\.codex\community-admin-shared-sync.md`
- 如果只是本地优化，不要默认直接上云；先本地验证，再决定是否同步测试环境
- 本地端口固定：
  - 后端 `18080`
  - 社区前台 `3106`
  - 后台 `3206`
  - 云镜像前台 `3107`
- 评论树最多两层显示，不要做无限递归 UI
- 判断视频是否已有真实 `preview`，不能只看 `preview_asset_id`，还要看 `asset_role = preview`
- 判断图片是否已有真实 `cover`，不能只看 `cover_asset_id`，还要看语义角色是否真的是派生 `cover`
- `/media/**` 必须继续走代理控制器，不要再和静态资源 handler 重叠
