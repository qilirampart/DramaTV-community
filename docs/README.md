## 2. 各目录用途

### `01_总览`

放项目总览级文档。

适合回答：

- 项目现在到底在做什么
- 为什么是全栈项目
- 整体推进顺序是什么
- `PGC / PUGC / UGC` 怎么理解

### `02_研究`

放竞品、参考社区、公开资料研究。

适合回答：

- 参考社区怎么做
- 哪些做法可借鉴
- 哪些方向不要照搬

### `03_架构`

放系统设计与架构层文档。

适合回答：

- 服务怎么拆
- 业务流怎么走
- 技术栈怎么选
- 第一阶段边界怎么定

### `04_实施设计`

放已经能直接指导开发实现的文档。

适合回答：

- 表怎么建
- API 怎么拆
- 前后端如何联调
- 本地环境如何准备

### `90_模板与工具`

放模板、工具说明、排障说明，不进入主线阅读路径。

### `archive`

放已经被替代、已合并、仅保留历史价值的文档。

规则：

- 归档文档不作为当前主线依据
- 当前决策优先参考 `01_总览` 到 `04_实施设计`

## 5. 当前整理原则

这次整理遵循了 3 条原则：

1. 主目录只保留当前仍在使用的主线文档。
2. 重叠规划文档合并后，旧版归档，不让主目录出现双入口。
3. 模板、排障、历史稿不与架构和实施文档混放。
