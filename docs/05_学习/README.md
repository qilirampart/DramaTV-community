## 学习规则

- 每个学习主题单独建目录。
- 每个主题至少包含 `进度.md`、`错题与遗漏.md`、`复习计划.md`。
- 课程文件按 `01_...md`、`02_...md` 顺序追加。
- 学习内容只记录个人理解、课程、练习、遗漏和复习计划。
- 工程方案、部署方案、问题复盘仍放到对应的 `03_架构` 或 `04_实施设计`。

## 当前优先学习路径

1. 先学会用五层法拆功能：页面层、接口层、后端服务层、数据层、运行环境层。
2. 再用精选页做第一条真实代码链路拆解。
3. 然后拆作者主页和发布链路。
4. 最后补部署、回滚、媒体资源、后台运营配置等工程化能力。
