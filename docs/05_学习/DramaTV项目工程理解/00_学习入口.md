# DramaTV 项目工程理解学习入口

## 学习目标

把你现在对项目的理解，从“知道功能怎么用”升级为：

- 能解释功能如何实现
- 能顺着页面找到接口
- 能顺着接口找到后端服务
- 能知道后端大概查哪些表
- 能判断问题优先发生在哪一层
- 能向接手人讲清项目主链路
