# DramaTV 项目工程理解学习路线任务板

创建日期：`2026-06-21`

## 目标

这份任务板用于把后续学习从“零散问概念”收口成一条能直接帮助接手、排障、交接、部署的路线。

核心目标不是背知识点，而是围绕当前 `DramaTV` 项目做到：

- 能解释功能如何从页面走到接口、后端、数据库和媒体资源。
- 能理解本地、云端、Nginx、服务、数据库、OSS 之间的运行链路。
- 能用 Git 保护代码、看懂改动、组织提交和回滚。
- 能理解自动化部署脚本在做什么，知道部署失败时查哪里。
- 能把 AI 写出来的代码纳入工程安全边界，而不是只看页面效果。

## 推荐学习顺序

当前建议先走这条线：

```text
04 项目运行链路
-> 05 Git 基础
-> 06 DramaTV 真实 Git 流程
-> 09 自动化部署基础
-> 10 DramaTV 部署脚本拆解
-> 11 上线前后检查
-> 12 部署事故排查
```

原因：

- 你已经能理解不少功能现象，下一步要先理解系统如何跑起来。
- Git 是你和 AI 协作时最重要的安全带。
- 自动化部署只有在理解运行链路和 Git 后才有意义。
