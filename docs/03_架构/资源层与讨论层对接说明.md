# DramaTV 资源层与讨论层对接说明

对应图文件：

- `docs/03_架构/资源层与讨论层对接图.drawio`

## 1. 这张图主要说明什么

这张图不是视觉稿，而是用来把 DramaTV 当前页面结构讲清楚：

- 左边是资源对象层
- 右边是独立讨论层
- 底部是“已经接通的真实接口”和“后续预留的讨论接口”

## 2. 为什么要拆两层

如果不拆两层，项目很容易跑偏：

- 视频详情评论会被经验帖需求挤乱
- 工作流详情页会同时承担对象页和论坛页职责
- 首页主 feed 会被论坛帖流冲掉

拆成两层之后，边界会更清楚：

- 资源对象层继续走真实后端
- 独立讨论层先做前端骨架和接口预留

## 3. 当前最重要的结论

### 3.1 已接真实后端的页面

- 首页
- 视频详情页
- 工作流详情页
- 作者主页
- 发布页
- 画布运行态页

### 3.2 当前只是前端骨架的页面

- 讨论区首页
- 讨论帖详情页

### 3.3 后续补接口时的原则

- 对象评论不要和帖子系统混表
- 讨论帖要单独建实体
- 讨论帖与视频 / 工作流的关系通过绑定表表达

## 4. 这张图最适合怎么用

它适合三个场景：

1. 你自己确认项目有没有跑偏
2. 跟别人解释“为什么评论区和讨论区不是一个东西”
3. 后续接帖子接口时，快速判断该挂到哪一层
