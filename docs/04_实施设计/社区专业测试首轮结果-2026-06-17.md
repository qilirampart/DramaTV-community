## 3. 失败簇与分析

### 3.1 `smoke:api` 临时账号登录失败

复现命令：

```powershell
npm.cmd run smoke:api
```

复现结果：

- `8 passed / 11 failed`
- 首个失败点：
  - `auth.temp-user-login`
  - `401 AUTH_INVALID_CREDENTIALS`

根因分析：

- `scripts/run-local-community-api-smoke.mjs` 原先把临时账号密码默认写死为 `dramatv-local-dev`
- 当前本地后端实际 `apps/server/.env` 为：
  - `DRAMATV_COMMUNITY_AUTH_LOCAL_PASSWORD_ENABLED=true`
  - `DRAMATV_COMMUNITY_AUTH_LOCAL_PASSWORD_BOOTSTRAP_SECRET=123456`
- 这会导致：
  - 现有账号如 `creator-a` 仍可正常登录
  - 新建临时账号自举创建失败
  - 后续所有依赖临时账号的草稿、上传、互动、评论用例级联失败

已采取修复：

- `scripts/run-local-community-api-smoke.mjs`
  - 临时密码来源调整为按顺序读取：
    - `--temp-password`
    - `DRAMATV_SMOKE_TEMP_PASSWORD`
    - `DRAMATV_COMMUNITY_AUTH_LOCAL_PASSWORD_BOOTSTRAP_SECRET`
    - `apps/server/.env` 中同名配置
    - 最后才回退到创作者密码
- `apps/server/.env.example`
  - 补齐本地密码登录与 bootstrap secret 示例项
