# 本地开发环境准备

更新日期：2026-04-07

## 1. 结论先说

当前项目的本地开发环境主线是：

- 数据库：`PostgreSQL`
- 缓存：`Redis`
- 推荐启动方式：`Docker Compose`
- 可视化管理：优先用容器化 `pgAdmin`，不强制安装 `DataGrip` 或 `Navicat`

这台机器在 2026-04-07 的本地检查结果是：

- `Docker` 已安装，可直接使用
- `psql` 未安装
- `redis-cli` 未安装

所以最省事、最贴合当前仓库主线的方案，不是先装一堆客户端，而是直接把 `PostgreSQL + Redis` 用 Docker 跑起来。

## 2. 为什么不是 XAMPP MySQL

这个仓库已经明确按 `PostgreSQL` 设计，而不是按 `MySQL` 设计。

主要依据：

- 后端配置默认是 `jdbc:postgresql://...`
- 迁移脚本已经按 PostgreSQL 能力建模
- 表设计中已经用到或预留了 PostgreSQL 侧常见能力，例如：
  - `jsonb`
  - `text[]`
  - `gin`
  - `timestamptz`
  - `pgcrypto`

所以：

- `XAMPP MySQL` 可以继续留给别的项目
- 但它不应该作为 DramaTV 社区项目的主线数据库

## 3. 仓库里新增的本地环境入口

本次已经补好以下文件：

- `infra/local/docker-compose.yml`
- `infra/local/.env.example`
- `apps/server/.env.example`

## 4. 启动步骤

### 4.1 复制环境文件

在项目根目录执行：

```powershell
Copy-Item infra\local\.env.example infra\local\.env
```

如果后面需要改端口、账号密码，就改 `infra/local/.env`。

### 4.2 启动 PostgreSQL + Redis

在项目根目录执行：

```powershell
docker compose -f infra/local/docker-compose.yml --env-file infra/local/.env up -d
```

### 4.3 如果你想要图形化管理数据库

继续执行：

```powershell
docker compose -f infra/local/docker-compose.yml --env-file infra/local/.env --profile tools up -d
```

然后访问：

- `pgAdmin`：`http://127.0.0.1:5050`

默认登录账号密码取自 `infra/local/.env`：

- `PGADMIN_DEFAULT_EMAIL`
- `PGADMIN_DEFAULT_PASSWORD`

默认示例值是：

- `PGADMIN_DEFAULT_EMAIL=admin@dramatv.com`
- `PGADMIN_DEFAULT_PASSWORD=dramatv-admin`

## 5. 默认连接信息

### PostgreSQL

- Host：`127.0.0.1`
- Port：`5432`
- Database：`dramatv`
- Username：`dramatv`
- Password：`dramatv`

### Redis

- Host：`127.0.0.1`
- Port：`6379`

## 6. pgAdmin 里如何连 PostgreSQL

打开 `pgAdmin` 后新增一个 Server：

- Name：`DramaTV Local PG`
- Host name/address：`postgres`
- Port：`5432`
- Maintenance database：`dramatv`
- Username：`dramatv`
- Password：`dramatv`

这里建议填 `postgres`，因为 `pgAdmin` 和 `PostgreSQL` 都在同一个 Docker 网络里。

如果你使用本机安装的数据库客户端，而不是容器里的 `pgAdmin`，那就连接：

- Host：`127.0.0.1`
- Port：`5432`

## 7. 后端环境变量

后端本地环境变量示例已经放在：

- `apps/server/.env.example`

核心变量如下：

```bash
DRAMATV_DB_URL=jdbc:postgresql://127.0.0.1:5432/dramatv
DRAMATV_DB_USERNAME=dramatv
DRAMATV_DB_PASSWORD=dramatv
DRAMATV_REDIS_HOST=127.0.0.1
DRAMATV_REDIS_PORT=6379
```

## 8. 当前阶段要注意的事

当前本地开发已经按全链路模式推进，数据库与缓存环境准备好之后，还需要补齐：

- `Java 17+`
- `Maven 3.6.3+`

## 9. 推荐顺序

推荐你现在按这个顺序走：

1. 先用 Docker 启动 `PostgreSQL + Redis`
2. 用 `pgAdmin` 验证数据库能连通
3. 再安装 `Java 17`
4. 再安装 `Maven`
5. 然后继续把发布草稿、评论、工作流复制等链路稳定在真实数据库上

## 10. 常用命令

### 查看容器状态

```powershell
docker compose -f infra/local/docker-compose.yml --env-file infra/local/.env ps
```

### 停止容器

```powershell
docker compose -f infra/local/docker-compose.yml --env-file infra/local/.env down
```

### 查看 PostgreSQL 日志

```powershell
docker compose -f infra/local/docker-compose.yml --env-file infra/local/.env logs postgres
```

### 查看 Redis 日志

```powershell
docker compose -f infra/local/docker-compose.yml --env-file infra/local/.env logs redis
```

## 11. 这一步完成后的标准

满足下面 3 条，就算本地数据库环境准备完成：

1. `docker compose ... ps` 能看到 `postgres` 和 `redis` 都是运行态
2. `pgAdmin` 能登录，并能连上 `dramatv` 数据库
3. 后端环境变量已经知道该怎么指向 `127.0.0.1:5432` 和 `127.0.0.1:6379`
