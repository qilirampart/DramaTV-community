# 云端社区多维度测试用例

日期：`2026-06-16`

适用环境：`测试云环境 / drama-community-dev.dzkjm.cn`

适用范围：`apps/web + apps/server` 社区前台主链路

## 1. 测试概览

本轮测试目标不是只验证单个功能可用，而是验证云端社区在真实数据、真实登录态、真实长链路切换下是否还存在隐藏问题。

本轮重点覆盖 4 类风险：

1. 主链路可用性风险
2. 深滚动与返回定位风险
3. 登录态 / 会话 / 跳转一致性风险
4. 真实云数据下的分类、搜索、媒体与内容混排风险

## 2. 功能地图

当前社区前台可测正式功能面：

1. 登录页 `/login`
2. 首页 `/`、`/home`
3. 精选页 `/featured`
4. 讨论区 `/discussions`、发帖 `/discussions/new`、帖子详情 `/discussions/[slug]`
5. 发布页 `/publish`
6. 个人中心 `/me`
7. 作者主页 `/creators/[id]`
8. 视频详情 `/videos/[id]`
9. 提示词详情 `/prompts/[id]`
10. 工作流详情 `/workflows/[id]`
11. 外部画布入口 `/canvas` 及运行时跳转链路
12. 全局能力：返回定位、主题切换、通知、收藏点赞评论关注、举报、媒体加载

## 3. 测试假设与边界

### 3.1 假设

1. 云端测试账号可用：`psk / 123456`
2. 云端环境存在足够的精选资源、作者页作品、帖子与提示词数据
3. 当前测试以桌面端 Chrome 类浏览器行为为主

### 3.2 边界

1. 本轮不覆盖后台运营端完整回归
2. 本轮不覆盖正式公网性能压测，只做真实浏览器长链路稳定性检查
3. 画布外链只验证入口和跳转语义，不深挖外部站点业务

## 4. 测试点

### 4.1 主链路

- 登录、登出、登录后重定向
- 首页首屏、精选首屏、讨论区首屏可用
- 详情页可打开且主内容正常
- 个人中心、作者主页、发布页可进入

### 4.2 导航与返回定位

- 列表进入详情后返回能否回到进入位置
- 深滚动后返回是否仍生效
- `featured -> detail -> creator -> creator work detail -> back -> back`
- `discussions -> post detail -> creator -> back`
- 顶部导航切换后是否状态错乱

### 4.3 精选页高风险点

- 大分类切换
- 小分类切换
- 快速连点切换
- 搜索与筛选组合
- 深滚动自动加载
- 瀑布流列分布稳定性
- 深滚动后点击详情、返回、再切分类

### 4.4 讨论区高风险点

- 频道切换
- 帖子详情打开
- 返回列表定位
- 发帖入口登录态守卫
- 社区内容卡片只保留标题后的布局稳定性

### 4.5 作者页 / 个人中心

- 作品列表加载
- `查看更多`
- 深层作品进入详情再返回
- 第一次返回定位是否生效
- 多次往返后是否丢失列表状态

### 4.6 登录态 / 会话

- 未登录访问受保护页跳登录
- 登录后跳回来源页
- 长时间浏览、深滚动、多跳转后是否意外掉登录
- 登录页本身是否错误保留已登录壳态

### 4.7 媒体与内容语义

- 图片 / 视频 / 工作流 / 帖子是否混入错误分类
- 精选页是否错误出现帖子
- 活动/其他分类下是否混入不应出现的帖子
- 提示词详情、视频详情、作者页、社区页封面与标题显示是否一致

### 4.8 UI 与交互一致性

- 夜间 / 日间模式文本可读性
- 卡片标题高度是否失控
- 加载中、查看更多、空态是否闪烁切换
- 首屏与列表区是否出现明显偏移、错列、塌列

### 4.9 异常与观测性

- 页面异常时是否有稳定错误提示
- 控制台是否出现明显脚本错误
- 接口失败是否出现大面积白屏或卡死

## 9. 2026-06-16 第三轮执行结果补记

本轮是对前两轮高风险结论的复核，重点不是“链接是否看起来对了”，而是“真实点击后是否回到了正确位置，且链路没有丢状态”。

### 9.1 已确认通过

1. 帖子详情返回定位
   - 实测路径：
     - `/discussions -> /discussions/weekly-creator-thread -> 社区`
   - 实测结果：
     - 返回地址为 `/discussions#discussion-thread-98b8a9e5-61b1-4bf9-94fd-2ed845de886a`
     - 目标帖子卡片成功进入视口
     - 当前云端版本不再符合前一轮“只会回到 /discussions 顶部”的旧结论

2. 精选深滚动多跳返回链
   - 实测路径：
     - `/featured` 深滚动至 `180` 条
     - 进入 `/prompts/f6b41e94-a1b1-425a-a3f8-9c1401bbd240`
     - 进入作者 `community`
     - 点击 `查看更多`，作者页作品数 `24 -> 48`
     - 进入更深一层作者作品详情
     - 返回作者页
     - 返回中间提示词详情
     - 返回精选页
   - 实测结果：
     - 作者页返回后仍保留 `48` 条，不再掉回 `24`
     - 作者页目标卡片成功回到视口
     - 中间提示词详情页没有被越级跳过
     - 返回精选页后仍保留 `180` 条数据
     - 精选目标卡片成功回到视口
     - 未出现 `Restoring creator position` / `Restoring featured position` 卡死

3. 深精选页进入个人页再返回
   - 实测路径：
     - `/featured#featured-item-f6b41e94-a1b1-425a-a3f8-9c1401bbd240 -> /me -> 返回首页`
   - 实测结果：
     - 能回到原精选锚点
     - 返回后仍保留 `180` 条数据
