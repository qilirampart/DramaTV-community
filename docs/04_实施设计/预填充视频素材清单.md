## 3. 推荐使用方式

### 3.1 用作页面预填充素材

这批视频最适合优先用于：

- 首页精选视频卡
- 视频详情页主资源占位
- 作者主页作品预填充
- 工作流详情页关联案例视频
- 讨论区经验帖里的案例资源

### 3.2 用作本地 seed 或 smoke 演示资源

如果后面要给本地数据库补更多演示内容，建议直接引用 `manifest.json` 里的稳定路径，不要再从归档目录读取原文件名。

### 3.3 暂时不要做的事

- 不要在列表页默认自动播放整批视频
- 不要继续把归档目录当正式资源目录
- 不要把超长中文提示词文件名直接当公开 URL

## 4. 当前素材特点

这批素材的风格比较集中，适合 DramaTV 第一阶段：

- 武侠 / 仙侠
- 赛博 / 科幻
- 舞蹈 / 舞台
- 动作 / 打戏

这和当前社区“作品 + 工作流 + 创作者 + 经验讨论”的主线是匹配的。

## 5. 已知注意事项

### 5.1 `012-moves-showcase.mp4` 体积明显更大

这条素材体积在当前目录里最大，适合：

- 详情页
- 工作流案例
- 专题页

不适合：

- 首页多卡片同时自动加载

### 5.2 当前正式前端还没有真正的视频播放层

现在正式前端已经能访问这些资源，但视频详情页当前仍以封面型展示为主。

也就是说：

- 素材已经就位
- 资源路径已经稳定
- 后续还需要在界面重构时把真正的视频播放组件补上

## 6. 下一步最合适怎么接

我建议后面按这个顺序使用这批素材：

1. 先在首页和视频详情页改版时接入 3 到 5 条代表性视频
2. 再补对应 poster / cover 抽帧资源
3. 最后再考虑把部分素材写入本地数据库，作为真实演示内容
