# 首页精选档案异形拼贴 UI 优化任务板

状态: `进行中`
创建日期: `2026-06-09`
适用范围: `apps/web`
目标区域: 首页 `精选档案` 区块

## 1. 背景

当前首页 `精选档案` 使用的是统一比例卡片网格，展示稳定，但存在两个明显问题:

1. 资源统一裁切成固定比例，很多图片/视频的真实视觉比例被压扁或截断。
2. 卡片全都长得一样，信息层级和主次关系不够明显，和参考目标 `https://jimeng.jianying.com/ai-tool/home` 的资源拼贴感差距较大。

本轮不是做全站改版，而是只先改首页这一块，先把资源展示方式从“统一卡片墙”升级到“有主次的异形拼贴区”。

## 2. 已定方案

### 2.1 本轮采纳方案

采用:

- `比例分桶`
- `固定模板`
- `轻裁切`
- `无空位填槽`

具体含义:

- 先按资源视觉比例把卡片归类为 `portrait / square / landscape / wide`
- 再把不同类型资源填入预设好的几种卡位模板
- 模板本身负责实现紧密排版，不追求每张卡片 100% 原始比例展示
- 图片/视频继续允许轻微裁切，以换取首页拼贴区整体不留空位

### 2.2 明确不采用的方案

- 不采用纯 `Masonry / 瀑布流`
  - 原因: 比例保真高，但首页会更像素材库，不像即梦这种编辑化拼贴首页
- 不继续采用“所有卡片统一 16:9 + 统一网格”
  - 原因: 裁切过重，且视觉层级不成立

### 2.3 当前约束

当前首页卡片流还没有完整消费真实 `width / height` 元数据，因此本轮分两阶段推进:

1. 第一阶段:
   - 先用现有首页卡片数据做异形模板版
   - 优先解决“全都一个比例”和“没有主次”的问题
2. 第二阶段:
   - 如果第一阶段仍然裁切过重，再把真实比例元数据补进首页卡片契约
   - 让“资源比例决定卡位选择”更准确

## 3. 目标与非目标

### 3.1 本轮目标

- 首页 `精选档案` 形成即梦风格的资源拼贴感
- 卡片有明显主次和节奏，不再统一尺寸
- 布局紧密，不出现明显空槽
- 保留现有真实数据、悬浮播放、跳转和返回定位能力
- 移动端能平滑退化，不因异形布局导致可读性崩坏

### 3.2 本轮非目标

- 不重做整站列表布局
- 不把 `精选页`、`社区页`、`作者页` 一起改成同一套拼贴系统
- 不在第一步就重构所有后端接口
- 不做纯视觉复刻，不追求和即梦逐像素一致

## 6. 风险与处理

### 风险 1: 当前首页缺少真实比例元数据

影响:
第一阶段无法做到完全按原图比例排版。

处理:
先用模板版解决“无层级”和“裁切过统一”的问题，再视结果决定是否启动 `U8-6`。

### 风险 2: 紧密布局和悬浮播放互相干扰

影响:
视频卡 hover 播放可能在新卡位里出现闪烁、裁切或性能噪声。

处理:
先保留现有悬浮播放能力，只针对新卡位修正媒体层和遮罩层，不轻易扩大发热范围。

### 风险 3: 移动端直接继承桌面异形布局会崩

影响:
手机端可能出现可点区域混乱、信息过密或阅读节奏断裂。

处理:
明确 `U8-4` 独立收口，移动端允许退化，不强保桌面模板关系。
