# 共享 ECS 自定义域名内部分流演练
创建日期：`2026-06-11`
适用环境：`8.141.20.130` 共享测试 ECS

## 1. 目标

这份演练只解决一件事：

- 在**不影响同事项目**的前提下，验证某个自定义域名是否可以正确命中 DramaTV 社区前台和后台。

这不是正式公网切换方案，也不等价于“备案、证书、接入校验全部打通”。

## 2. 两层验证必须分开看

### 2.1 内部分流验证

验证目标：

- 社区 Nginx `server_name` 已包含目标域名
- `Host: 目标域名` 时，`/login` 命中社区前台
- `Host: 目标域名` 时，`/admin/login` 命中社区后台

这层验证通过，只能说明：

- 同机三项目的 Host 分流没有串项目
- 这个域名作为社区入口在 Nginx 路由层是可用的

### 2.2 公网边缘验证

验证目标：

- 从外部访问 `http://目标域名/login`
- 从外部访问 `http://目标域名/admin/login`

这层即使失败，也不代表社区代码有问题。它还会受到以下因素影响：

- 阿里云 ICP / 接入校验
- 阿里云安全组
- 域名 DNS 解析
- 备案 / 接入备案状态

## 3. 已新增的脚本

脚本路径：

- [scripts/set-test-community-domain-alias.ps1](/E:/点众/DramaTV社区搭建/scripts/set-test-community-domain-alias.ps1)

能力：

1. 给社区 Nginx 配置增加一个域名别名，或移除该别名。
2. 自动备份远端社区 Nginx 配置。
3. 自动执行 ECS 内部 `Host` 头验证。
4. 默认附带本地 `curl --resolve` 公网边缘探测。

## 4. 使用方式

### 4.1 增加域名别名

```powershell
./scripts/set-test-community-domain-alias.ps1 -Domain your.domain.com
```

### 4.2 移除域名别名

```powershell
./scripts/set-test-community-domain-alias.ps1 -Domain your.domain.com -Remove
```

### 4.3 只做内部修改和 ECS 内部验证，不做本地公网探测

```powershell
./scripts/set-test-community-domain-alias.ps1 -Domain your.domain.com -SkipPublicProbe
```

## 5. 安全边界

这个脚本的边界是：

- 只修改社区自己的 `/etc/nginx/conf.d/dramatv-community-http.conf`
- 不修改 DramaLoom
- 不修改法务相似度项目
- 不改裸 IP 兜底规则
- 不改同事项目现有 `server_name`

## 6. 判定标准

### 内部分流成功

至少满足：

1. `curl -H "Host: 目标域名" http://127.0.0.1/login` 返回社区前台登录页。
2. `curl -H "Host: 目标域名" http://127.0.0.1/admin/login` 返回社区后台登录页。
3. `nginx -t` 成功且 reload 成功。

### 公网可访问

还要额外满足：

1. 域名 DNS 已正确指向 `8.141.20.130`
2. 阿里云安全组已放通对应端口
3. 未被阿里云 ICP / 接入校验拦截
4. 备案 / 接入备案状态允许访问

## 7. 推荐流程

建议顺序：

1. 先跑脚本，完成社区 Nginx 域名别名和 ECS 内部分流验证。
2. 再看本地 `curl --resolve` 探测是否已经能穿透公网边缘。
3. 如果内部分流成功，但公网仍失败，优先排查接入层，不要误判为社区前后端故障。
4. 如果后续决定不用该域名，立刻执行 `-Remove` 回滚。

## 8. 一句话总结

这套演练的目的，是先确认“这个域名会不会把请求打到社区项目本身”，而不是直接宣称“这个域名已经可以正式对外用了”。
