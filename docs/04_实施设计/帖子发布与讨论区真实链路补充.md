# 帖子发布与讨论区真实链路补充

更新日期：2026-04-10

## 1. 目的

这份补充文档用于承接本轮已经落地的两条真实链路：

- 帖子发布：`post-drafts`
- 讨论区读取：`discussions`

当前仓库已不再把讨论区当作静态占位页面处理，`/discussions`、`/discussions/[slug]`、`/publish` 的帖子发布入口都已经切到真实后端接口。

## 2. 已落地接口

### 2.1 讨论区读取

- `GET /api/discussions/home`
  - 权限：`public`
  - 用途：讨论区首页，返回频道列表与精选帖子列表
- `GET /api/discussions/threads/{slug}`
  - 权限：`public`
  - 用途：帖子详情页，按 `slug` 读取真实讨论帖

### 2.2 帖子草稿

- `POST /api/post-drafts`
  - 权限：`creator`
  - 用途：创建或复用帖子草稿
- `GET /api/post-drafts/{id}`
  - 权限：`creator`
  - 用途：读取帖子草稿
- `PUT /api/post-drafts/{id}`
  - 权限：`creator`
  - 用途：保存帖子草稿
- `POST /api/post-drafts/{id}/submit`
  - 权限：`creator`
  - 用途：提交帖子草稿，并写入 `discussion_threads`
  - 返回补充：当前已同时返回 `targetId` 与 `slug`

### 2.3 评论扩展

- `POST /api/comments`
  - `targetType` 新增支持：`post`
- `GET /api/comments?targetType=post&targetId=...`
  - 用途：帖子详情页回复列表

## 3. 帖子草稿字段

帖子草稿当前最小字段如下：

```ts
type PostDraft = {
  draftId: string
  targetId?: string
  title?: string
  channelSlug: string
  content?: string
  tagNames: string[]
  bindingTargetType?: 'video' | 'workflow'
  bindingTargetId?: string
  statusCode: string
}
```

说明：

- `channelSlug` 当前真实可用频道至少包含：
  - `video-production`
  - `prompt-lab`
- `bindingTargetType` 只允许 `video | workflow`
- `bindingTargetId` 必须指向已发布内容，否则后端返回业务错误

## 4. 页面数据契约增量

### 4.1 `/publish`

当前发布页主入口已经收口为两类：

- `video`
- `post`

工作流发布不再作为当前阶段的独立第一入口，而是作为“视频发布的可选附带工作流”存在。

```ts
type PublishPageView = {

    id: string

    roleCode: string

  activeTab: 'video' | 'post'
  videoDraft: VideoDraftView
  workflowDraft: WorkflowDraftView

}
```

### 4.2 `/discussions`

type DiscussionHubPageView = {
