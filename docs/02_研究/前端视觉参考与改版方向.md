# DramaTV 前端视觉参考与改版方向

这份文档用于把外部设计参考库和我们已经明确的社区能力收敛成一套可执行的前端改版方向。

## 1. 本地已保存的外部参考库

已保存：

- `docs/98_外部参考/awesome-design-md`

这个仓库里包含 50+ 套网站风格的 `DESIGN.md`、`preview.html` 与 `preview-dark.html`，适合作为“视觉语言参考库”，而不是直接拿来当成我们的网站模板。

## 2. 对 DramaTV 最有价值的参考

### 2.1 RunwayML

参考路径：

- `docs/98_外部参考/awesome-design-md/design-md/runwayml/DESIGN.md`

适合借鉴：

- 首页 Hero 的电影感与沉浸式大画面
- 视频详情页的媒体优先布局
- 深色背景下让作品本身承担主要视觉冲击

不建议照搬：

- 过度“界面隐形”，会削弱社区的讨论、评论、工作流入口和创作者关系
- 完全依赖大视觉，容易让信息密度不足

### 2.2 Pinterest

参考路径：

- `docs/98_外部参考/awesome-design-md/design-md/pinterest/DESIGN.md`

适合借鉴：

- 首页发现流的浏览节奏
- 创作者主页中作品与工作流的陈列感
- 卡片瀑布流/拼贴流的视觉启发

不建议照搬：

- 品牌红与暖白体系不适合我们当前的 AI 视频、画布、工作流语境
- 过强的生活方式气质会冲淡“创作方法”和“工具联动”感

### 2.3 Linear

参考路径：

- `docs/98_外部参考/awesome-design-md/design-md/linear.app/DESIGN.md`

适合借鉴：

- 发布页与工作流详情页的产品化秩序感
- 表单、按钮、面板、状态标签的统一层级
- 开发态工具页、创作者工作台、编辑态场景的精确界面语言

不建议照搬：

- 过强的工程工具感会让首页与视频详情页太冷
- 紫色品牌感不应直接进入 DramaTV

### 2.4 Spotify

参考路径：

- `docs/98_外部参考/awesome-design-md/design-md/spotify/DESIGN.md`

适合借鉴：

- 深色沉浸式内容容器
- 强主次关系的按钮系统
- 内容主导、界面退后的整体氛围

不建议照搬：

- 过度 pill/circle 几何会把产品带向播放器而不是创作者社区
- 过强的音乐产品隐喻不适合视频 + 工作流社区

## 3. 必须结合的产品侧参考

视觉不能只看设计站点，还要和我们已经研究过的社区机制结合。

优先结合：

- `docs/02_研究/视频社区竞品研究简表.md`

其中最值得继续约束页面结构的对象包括：

- `Runway`：高质量 AI 视频社区的精选感与活动感
- `LiblibAI`：作品、工作流、创作者中心同站存在
- `RunningHub`：工作流不仅可看，还可运行、复制、接 API
- `TapTap`：内容对象详情页、评论区、作者/开发者主页的结构感

## 4. DramaTV 的建议视觉组合

不建议模仿单一站点。

更适合 DramaTV 的组合是：

- `RunwayML 50%`
- `Linear 30%`
- `Pinterest 20%`

对应解释：

- `RunwayML` 负责首页与视频内容的第一眼冲击
- `Linear` 负责工作流、发布、编辑、状态和信息密度
- `Pinterest` 负责作品/工作流陈列时的发现感和浏览节奏

## 5. 五个核心页面的改版方向

### 5.1 社区首页

方向：

- 顶部不是普通 SaaS Hero，而是“精选片场 + 推荐流”
- 首屏用大视觉建立 AI 视频社区气质
- 首屏以下快速进入作品、工作流、创作者三个主入口

参考来源：

- 视觉氛围：`RunwayML`
- 列表组织：`Pinterest`
- 信息控件：`Linear`

### 5.2 视频详情页

方向：

- 视频是主角，简介、标签、作者、来源工作流围绕主视觉排布
- 评论区不能像博客页，而要更像社区对象详情页
- “继续创作 / 查看工作流 / 进入作者主页”必须明显

参考来源：

- 媒体氛围：`RunwayML`
- 结构关系：`TapTap` + `LiblibAI`

### 5.3 工作流详情页

方向：

- 强调“方法”而不是“附件”
- 结构上更像精致的产品对象页，而不是图文帖子
- 复制工作流、在画布中打开、查看关联作品应成为主操作

参考来源：

- 界面秩序：`Linear`
- 产品语义：`RunningHub` + `LiblibAI`

### 5.4 创作者主页

方向：

- 同时展示作品与工作流
- 页面氛围要像“作者片场”，不是普通用户资料页
- 顶部展示作者定位、方法风格、代表内容

参考来源：

- 内容陈列：`Pinterest`
- 创作者中心感：`LiblibAI`

### 5.5 发布页

方向：

- 不再像简单表单
- 逐步接近“创作者工作台 / 发布中心”
- 上传作品、绑定工作流、添加标签与说明要形成层次

参考来源：

- 结构与控件：`Linear`
- 内容氛围：适度吸收 `RunwayML`

## 6. 改版时要避免的误区

- 不要做成官网 landing page
- 不要做成普通短视频平台
- 不要把工作流弱化成视频附件
- 不要把页面全都做成统一的工具后台风格
- 不要直接照搬外部网站的品牌色、专有字体和细节

## 7. 下一步建议

下一步前端重构建议按这个顺序推进：

1. 先输出 DramaTV 自己的 `DESIGN.md`
2. 先改全局样式与导航框架
3. 再统一卡片系统
4. 然后重构五个核心页面
5. 最后再补动画、微交互与响应式细节
